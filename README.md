# 新款旅游系统旅行社研学游景点门票等各类旅游服务周边游国内游多端管理小程序源码

源码获取：ym7k.com/13517/

这套旅游行业多端管理源码采用 **FastAdmin+ThinkPHP+Uniapp** 技术开发，一套源码适配微信小程序、H5，配套 PC 后台管理端，专为旅行社、文旅公司、研学机构、景区票务服务商打造，涵盖景点门票、周边游、国内长线游、研学旅行、定制游等旅游业务，支持产品上架、线上下单、预约核销、订单财务、分销推广、客户管理，私有化部署，方便二次开发。

## 一、技术架构

后端基于 ThinkPHP + FastAdmin 后台框架，自带 RBAC 权限、图片上传、Excel 导出、短信、支付、核销等基础组件；前端 Uniapp 开发，可打包微信小程序、H5，可按需拓展 APP；后台统一管理所有旅游产品、订单、游客、核销员、营销数据，更换 LOGO、轮播、分类即可快速上线文旅平台。

## 二、核心业务板块

### 1. 景点门票模块

景区门票上架，设置成人票、儿童票、优待票等多票种；设置票价、库存、使用有效期、预约须知、退改规则；游客线上购买，下单后获取核销码 / 二维码，到景区闸机或者前台扫码核销；支持分时预约，限制每日入园名额。

### 2. 跟团游线路

周边短途游、国内长线游线路发布，填写行程安排、出发日期集合地点、住宿标准、包含项目、不包含项目、注意事项；设置多期发团班次、余票数量；游客选择出行日期下单报名，支持多人报名填写游客实名信息（身份证用于保险）。

### 3. 研学旅行（特色板块）

研学课程、研学营、亲子研学产品独立分类；可上传研学方案、研学亮点、师资介绍、安全保障、营期时间；支持学校、机构批量报名，后台导出报名名单、学生信息，适合研学机构、旅行社对接学校研学业务。

### 4. 定制游 / 私家团

用户提交定制需求，填写出行人数、目的地、出行时间、预算、需求说明；后台收到需求单，销售跟进报价、方案沟通，适合高端私家团、企业团建定制。

### 5. 酒店、租车、导游服务（可选拓展）

可拓展酒店预订、车辆租赁、导游预约等增值旅游服务，丰富平台营收渠道。

## 三、小程序用户端功能

- 微信一键授权登录，首页轮播、产品分类、热门推荐、专题活动
- 产品详情：图文相册、行程介绍、套餐选择、日期选择、在线下单支付
- 实名信息填报：出行人信息收集，用于买保险、景区核验
- 我的订单：待付款、待出行、已完成、已退款订单，电子票、核销码查看
- 预约核销：二维码核销凭证
- 收藏、咨询客服、一键联系商家
- 分销中心：分享线路、门票生成推广海报，下级下单拿佣金
- 优惠券、限时特惠、拼团等营销活动

## 四、后台管理核心功能

1. **产品管理**：门票、跟团线路、研学产品、定制游管理，上架、下架、设置库存、价格、退改规则、班次管理
2. **订单 & 核销管理**：全部订单查看、退款审核、核销记录；核销员账号单独分配权限，支持扫码枪、小程序端扫码验票
3. **游客信息管理**：出行人实名信息台账，支持导出 Excel，方便购买旅游意外险
4. **分销管理**：分销开关、佣金比例设置、推广记录、佣金明细、提现审核
5. **分类管理**：自定义分类：周边游、国内游、研学、门票、亲子游等
6. **营销工具**：优惠券、限时活动、拼团、套餐组合
7. **数据看板**：订单营收、销量统计、新增用户图表，业务报表导出
8. **系统配置**：支付接口、短信通知、退改模板、协议设置、敏感词过滤、角色权限
